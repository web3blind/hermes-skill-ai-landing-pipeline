## 4. Section map

Recommended baseline:

1. Hero: clear promise + CTA + proof/visual.
2. Problem/context: why this matters.
3. Solution/product: what exists and how it helps.
4. Features/benefits: 3-5 concrete points.
5. Proof: examples, screenshots, numbers, testimonials, partners, prior work.
6. Process/how it works: simple steps if needed.
7. FAQ/objections: price, trust, setup, risk, who it is for/not for.
8. Final CTA.
9. Footer: links, contacts, legal/community links.

Adapt the map to the project; do not include empty sections just to fill space.

## 5. Draft copy

For each section:
- heading;
- 1-2 sentence body;
- CTA/link if any;
- visual/asset needed;
- proof/trust element if any.
